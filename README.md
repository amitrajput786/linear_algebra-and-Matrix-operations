# Linear Algebra and Matrix Operations

A collection of Python scripts solving mathematical problems related to linear algebra, matrix operations, and coding challenges.

## Overview

This repository contains solutions to various problems including matrix operations, subarray sum problems, and algorithm challenges (inspired by NeetCode). The project demonstrates implementations of common data structure and algorithm problems with focus on mathematical operations.

## Project Files

### Core Solutions
- **Day-1_matrix_op.py**: Solves subarray problems for target sum using a 2D matrix approach. Finds all subarrays that sum to a given target value.
  - Class: `solution`
  - Method: `sub_tar_sum(arr, target)` - Returns list of subarrays with sum equal to target

- **day-2_sub_question.py**: Secondary subarray question implementation

- **day-3_spiral.py**: Spiral matrix or spiral traversal operations

- **neetcode_problem-49.py**: Group of anagrams problem (LeetCode style)
  - Given an array of strings, groups anagrams together
  - Example: `["eat","tea","tan","ate","nat","bat"]` → `[["bat"],["nat","tan"],["ate","eat","tea"]]`

## Problem Categories

1. **Matrix Operations**: Working with 2D and 3D matrices
2. **Subarray Problems**: Finding subarrays with specific properties (target sum)
3. **String Algorithms**: Grouping and sorting problems (anagrams)
4. **Data Structures**: Hash maps, default dictionaries for efficient solutions
